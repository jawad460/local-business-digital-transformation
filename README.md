# 🦷 Dental Clinic Digital Transformation

## 📌 Overview
This project focuses on improving the digital presence of a local dental clinic using simple but effective technological solutions.

## 🚀 Key Contributions
- Added the clinic to Google Maps
- Built a website using AI tools
- Created a centralized Linktree for easy access
- Designed and implemented QR codes for customer engagement

## 📊 Impact
- 10+ new customers from Google Maps
- 20–30 QR code scans within 3 days
- Increased customer interaction and visibility

## 🎯 Motivation
This project was initiated to support my family's business during financial challenges and to apply my passion for technology in solving real-world problems.

## 🛠️ Tools & Technologies
- AI Website Builder
- Google Maps
- Linktree
- QR Code Generators
